Why we built Renku OS

We love Haiku’s speed, its elegance and its BeOS heritage. We also wanted a home for modern AI and LLM tooling, and a project where contributions of any kind are welcome.

  1. 一

    Friendly to AI and LLMs

    First-class support for AI coding tools and LLM integrations. Use whatever helps you write good code, and tell us how you used it.

  2. 二

    Open to every contributor

    AI-assisted code is explicitly allowed. Review is open and so is governance, and the rules are written down.

  3. 三

    BeOS heritage

    Built on the Haiku codebase, so it inherits BeOS’s speed, its clean C++ API and a very responsive desktop.

  4. 四

    An active community

    A small, fast-growing group of OS enthusiasts who meet on the forum, in Telegram and in pull requests.

連句 · ren-ku

Linked verse, linked code.

Renku is a Japanese form of collaborative poetry. One poet writes a verse, the next answers it, and the poem keeps moving forward because nobody writes it alone.

An operating system grows the same way. A driver answers a bug report, a port answers a request, and a review answers a patch.

a cursor blinking
on a screen that boots too fast
— someone types a line

another answers in code,
the kernel hums its reply

morning pull request:
a stranger’s driver lands, and
the old laptop wakes

Waking up more machines

Recent nightlies add new drivers, many of them ported from FreeBSD, OpenBSD and Linux through Renku’s compatibility layers.

Chromebooks

Bring-up work on inexpensive hardware that often ends up at the back of a drawer.

MacBooks

Drivers that let older MacBooks run a BeOS-style desktop.

Raspberry Pi 4

Early support for a single-board computer found on many hobbyists’ desks.
