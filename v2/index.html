About

Why Renku OS

We love Haiku’s speed, its elegance and its BeOS heritage. We also wanted a home for modern AI and LLM tooling, and a project where contributions of any kind are welcome. AI-assisted code is explicitly allowed, and review and governance are open.

The name

Renku (連句) is a Japanese form of collaborative poetry. One poet writes a verse, the next answers it, and the poem keeps moving forward because nobody writes it alone. An operating system grows the same way.

Hardware

Recent nightlies add new drivers, many ported from FreeBSD, OpenBSD and Linux through Renku’s compatibility layers. Current work covers Chromebooks, older MacBooks and early support for the Raspberry Pi 4.
